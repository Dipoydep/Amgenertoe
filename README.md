# GENERATOR PREMIUM - AMGEN

Tool Termux buat premium-in akun Alight Motion via AxzyeDev API.

## Alur

1. Send Magic Link → email target dapat link verifikasi
2. Verify Account → dapat idToken + refreshToken
3. Apply Premium → akun jadi premium

## Install

```bash
pkg install git -y
git clone https://github.com/USERNAME/amgen.git
cd amgen
bash install.sh
amgen
```

## Menu

- [1] Send Magic Link
- [2] Verify Account
- [3] Apply Premium
- [4] Auto Flow (semua sekaligus)
- [5] Refresh Token
- [6] Keluar

## Catatan

Rate limit: 5 akun / 24 jam. Admin unlimited.
